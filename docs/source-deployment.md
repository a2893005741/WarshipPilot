## 初次部署要点

普通 Windows 虚拟环境中的 Python 可能包含开发电脑解释器的绝对路径。prepare-runtime.ps1 使用系统基础 Python、完整复制其标准库和 DLL，并替换 uv 的 Windows 重定向程序；启动器通过 rebase-runtime.ps1 为当前安装目录更新 pyvenv.cfg。

远端当前使用 D:\WarshipPilot-0.5.2-win-x64，最新数据在它的 data 下。初次部署按 22680 监听进程定位实际目录，优先复制该数据，保留旧安装和数据。旧 D:\WarshipPilot 会以带时间戳的目录备份。

远端 GitHub 直连超时，GitHub 镜像入口与清华 PyPI 可访问；deploy.yaml 的 Git.Repository 允许为该运行电脑配置镜像，Git.Branch 对应推送分支。安装器还会使用实际便携 Git 验证更新源，成功后才切换旧安装。

首次部署使用 scripts/deploy-remote.ps1，必须在已提交、干净的源码仓库运行。计划任务和桌面快捷方式通过隐藏窗口包装运行 WarshipPilot.bat，MuMu IPC 保持在已登录用户会话中。

记录、故障图片和便携运行环境不提交。后续仅提交和推送代码，运行电脑从网页或下次启动时更新。

## 第三阶段：远征按游戏倒计时调度（v0.8.0）

原脚本的收远征只看港区角标和槽位按钮，出征流程按固定时间回港（每 10 分钟 / 30 分钟），从不读取远征倒计时；原脚本里的数字模板（快修用量、战役剩余次数的多点找色）是别的字体和位置，不适用于倒计时。

- 远征任务收取完毕后进入出征-远征，从第一章逐章翻到最后一章（点击选中章的上/下一格，翻不动即到头），读取每个进行中远征的剩余时间；途中遇到其他章节已完成的远征一并收取。
- 下次运行 = 最早结束的远征 + 30 秒（至少 1 分钟）。没有进行中的远征时按“兜底间隔”；有倒计时无法识别时，取两者较早者。
- OCR 按 H:\ALAS\AzurPilot 的 module/ocr：Ocr/Digit/DigitCounter/Duration 接口、extract_letters → crop_to_text 预处理、alocr-en-us-v2.6 模型（bin/ocr_models）。rapidocr 依赖 opencv-python 与本项目的 headless 冲突，识别步骤（48 高度归一化 + CTC 解码）直接用 onnxruntime 实现。
- OCR 模板（module/ocr/template.py）在模型前先做字形匹配：assets/ocr/duration.png 来自实机截图；模型读出的新字形自动学习到 log/ocr/，不改动 Git 工作区。实测 27 帧模板与模型结果一致，模板约 0.5 ms，模型约 50 ms。
- 模型不可用时该行记为无法识别，调度退回兜底间隔，不中断任务。

## v0.9.0：利用游戏自身的远征跳转，只补读变化的章节

游戏逻辑：有远征完成时点击出征直接打开该远征所在章节；收取并继续派遣后自动跳到下一个已完成的章节，按顺序收完；没有可收的就停在最后派遣的章节。

- 全部章节读一遍时，记录每章选中图标的特征和各舰队的结束时刻，存于 log/expedition-timers.json（缓存，丢失只多一次全读）。
- 之后每轮只补读本轮收取过的章节（通常就是停留的那一章，不翻页），其余章节沿用记录；没有远征完成且记录里也没有该结束的舰队时，不进入游戏页面、零输入。
- 以下情况改为全部重读：没有记录、距上次全读超过 12 小时、章节认不出或翻页失败、记录中有舰队应已结束但本轮没有可收取的（例如在游戏里手动派遣或取消过远征）。
- 点击出征后等待港区离开再继续，不再在页面切换途中重复点击。
- 完成事件写明本轮是“全部章节重新读取 / 只补读收取章节 / 沿用记录”。

## v0.10.0：战役与任务奖励（原脚本函数）

两项都直接执行恢复出的原 Lua 函数（与方案C 出征相同的 LegacyVM 路径），不重写游戏流程：

- 战役 = 原 `打战役`：按“战役章节/难度/阵型/修理”打完当天次数；原函数内遇到远征完成会先调用原 `收远征`。结束时读取原函数自己的状态：`打战役时间戳` 已设置 = 今日次数用完，下次为次日“计划时间”（默认 00:10）；`战役泡澡时间戳` 已设置 = 有船泡澡，按原脚本 900000 ms 后再来；其他提前结束按“重试间隔”。
- 任务奖励 = 原 `收任务`：港区任务按钮有红点（79|684|2D59FF）才进入任务页，有“一键领取”（361|783|2ED9FF）就点，否则返回；没有红点零输入。按“检查间隔”（默认 30 分钟）运行。
